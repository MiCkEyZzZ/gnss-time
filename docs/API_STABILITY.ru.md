# Стабильность API

Этот документ описывает, на что в `gnss-time` можно безопасно полагаться
сейчас, что может измениться до `1.0` и к чему не стоит обращаться напрямую.
Он нужен потому, что `#[non_exhaustive]` и doc-комментарии описывают
стабильность каждого элемента по отдельности, а общей политики и полного
списка публичных элементов до сих пор не было.

## Semver-политика для `0.x`

Проект ещё не достиг 1.0 (`0.x`). Правило семантической
совместимости Cargo для `0.x` считает границей ломающих изменений **minor**:
`0.5.2` → `0.6.0` может ломать; `0.5.1` → `0.5.2` — не должен. Данный крейт
строго следует этому правилу с одним дополнением, специфичным для того, как
он устроен:

| Изменение                                                                                         | Бамп в `0.x`                                                                                                                                                                             |
| -----------------------------------------                                                         | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Новый вариант добавлен в enum с `#[non_exhaustive]`                                               | **patch**                                                                                                                                                                                |
| Новый метод добавлен существующему типу                                                           | **patch**                                                                                                                                                                                |
| Новое поле добавлено в структуру с `#[non_exhaustive]`                                            | **patch**                                                                                                                                                                                |
| Новый `impl` трейта для существующего типа                                                        | **patch**                                                                                                                                                                                |
| Элемент помечен как устаревший (`#[deprecated]`, сохранён и работает)                             | **patch**                                                                                                                                                                                |
| Новый `#[non_exhaustive]` публичный тип или свободная функция                                     | **minor**                                                                                                                                                                                |
| Новая встроенная запись таблицы високосных секунд (`tables/leap_seconds.rs`)                      | **patch** — обоснование ниже                                                                                                                                                             |
| Удаление элемента `#[deprecated]`                                                                 | **minor**                                                                                                                                                                                |
| Изменение сигнатуры публичной функции (включая её тип ошибки)                                     | **minor**                                                                                                                                                                                |
| Изменение формата вывода `Display` для любого публичного типа                                     | **minor**                                                                                                                                                                                |
| Добавление варианта в enum без `#[non_exhaustive]`                                                | **minor** (иначе это ломающее изменение для чужого `match`)                                                                                                                              |
| Расширение числового типа параметра (например, `u16` → `u32`, как `from_week_tow` в `#TIME-27.1`) | **minor** — места вызова могут сломаться, даже если изменение «более разрешающее», потому что вывод типов и generic-границы вроде `impl Into<u32>` могут выбрать другой тип              |
| Сужение числового типа параметра или изменение возвращаемого типа                                 | **major** (или minor до `1.0`, но с проверкой уровня major)                                                                                                                              |
| Изменение константы `TimeScale::OFFSET_TO_TAI` для существующей шкалы                             | **major** — это константа корректности, а не форма API; её изменение молча меняет *числовой результат* каждой конвертации пользователей, что хуже, чем ошибка компиляции                 |
| Повышение MSRV (`rust-version` в `Cargo.toml`)                                                    | **minor** — потребитель, зафиксированный на более старом тулчейне, вообще не сможет скомпилировать крейт; с его точки зрения это неотличимо от ломающего изменения                               |
| Понижение MSRV                                                                                    | **patch** — чисто аддитивно: всё, что компилировалось раньше, продолжает компилироваться                                                                                                       |

**Почему новая запись таблицы високосных секунд — *patch*, а не minor?**
Вставка високосной секунды объявляется IERS, это внешние, фактические
данные — она не меняет сигнатуру функций, тип ошибок или множество типов,
которые может называть вызывающий код. Она меняет только *числовой вывод*
`gps_to_utc`/`utc_to_gps` для моментов после новой записи — ровно так, как
об этом говорит собственная документация крейта (см. политику обновления в
`docs/LEAP_SECONDS.ru.md`). Рассматривать её как patch означает, что
пользователи получают исправленное поведение високосных секунд через обычный
`cargo update` — это и есть задуманное поведение; альтернатива (считать
каждую високосную секунду minor-бампом) приучила бы пользователей фиксировать
`gnss-time = "=0.5.2"` и молча работать с устаревшими данными високосных
секунд неопределённо долго.

**Почему расширение типа параметра выделено особо?** `#TIME-27.1` изменил
параметр `week` у `Time::<Gps>::from_week_tow` с `u16` на `u32`, чтобы
соответствовать `week() -> u32`. Для прямых вызовов это обычно
безопасно (значения `u16` по-прежнему конвертируются), но не всегда
безболезненно: вызов `from_week_tow(2345u16, …)` всё ещё компилируется
(целочисленные литералы бестиповые), но вызывающий код `let w: u16 = ...;
from_week_tow(w, ...)` теперь требует явного `w as u32` (или `.into()`), а
если вызов идёт через generic-обёртку вроде `impl Into<u32>`, выводимый тип
меняется.
Алиаса совместимости `from_week_tow_u16` не существует (ранний черновик этого
документа утверждал обратное); расширение — полноценное ломающее изменение,
зафиксированное в `CHANGELOG.md` в разделе `[0.7.0]`.

**Критерии перехода на `1.0` (ещё не выполнены):** каждый элемент ниже,
помеченный **Стабильно — до `1.0`**, прошёл полный цикл `0.x` без сообщений об
изменении сигнатуры или семантики; набор фаззинг-тестов (`fuzz/README.md`)
непрерывно работает в CI и ни разу не падал в течение как минимум одного релизного цикла; а
для каждого инварианта из `docs/INVARIANTS.ru.md` есть проходящий тест.

## Легенда стабильности

| Бейдж                        | Значение                                                                                                                                                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------    |
| 🟢 **Стабильно**             | Безопасно полагаться уже сейчас. Изменяется только по правилам `0.x` выше (т.е. для сигнатур/семантики трактуется как post-1.0; может пополняться элементами `#[non_exhaustive]` по таблице patch-бампов). |
| 🟡 **Стабильно — до `1.0`**  | Дизайн зафиксирован и проверен фаззингом и property-тестами, но ещё не прошёл полный релизный цикл без изменений. Ожидается переход в 🟢 без изменений на `1.0`.                                           |
| 🟠 **Нестабильно**           | Форма может ещё измениться. Использовать можно, но при зависимости от точной сигнатуры фиксируйте конкретную версию `0.x.y`.                                                                               |
| 🔴 **Внутренний**            | Не часть публичного контракта, даже если сейчас доступен. Не полагайтесь на него; см. рекомендации по [`#[doc(hidden)]`](#внутренние-элементы-которые-следует-пометить-dochidden).                         |

## Аудит: покрытие `#[non_exhaustive]`

Были проверены каждый публичный enum и каждая публичная структура,
предназначенный для будущего роста полей. Результат:

| Тип                    | `#[non_exhaustive]`?                          | Вердикт                                                                                                                                                                                                          |
| ---------------------- | -------------------------------------------   | -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------                                    |
| `GnssTimeError`        | ✅ да                                         | Корректно — новые варианты ошибок — это patch: они только добавляются.                                                                                                                                           |
| `LeapExtendError`      | ✅ да                                         | Корректно — набор ошибок `try_extend` может расти (например, будущий вариант вроде `OffsetOverflow`, найденный фаззингом, `CHANGELOG.md`).                                                                       |
| `ConvertResult<T>`     | ✅ да                                         | Корректно — сейчас `Exact`/`AmbiguousLeapSecond`; третий вариант (например, различающий, с какой стороны високосной секунды результат) вполне может появиться.                                                   |
| `ConversionKind`       | ✅ да                                         | Корректно — классификационный enum `matrix.rs`; новый вид понадобился бы при добавлении шкалы с действительно новым типом связи.                                                                                 |
| `ScaleId`              | ✅ да                                         | Корректно — `#[non_exhaustive]` enum из шести шкал для интроспекции во время выполнения; добавление шкалы добавляет вариант, безопасно благодаря атрибуту.                                                       |
| `DisplayStyle`         | ✅ да                                         | Корректно — внутренний для ассоциированной константы `TimeScale::DISPLAY_STYLE` в `scale.rs`; новые стили отображения правдоподобны (например, стиль `CivilLike`, если у другой шкалы появится календарный вид). |
| `OffsetToTai`          | ✅ да                                         | Корректно — сейчас `Fixed(i64)`/`Contextual`; соответствует разделению Fixed/Contextual в `docs/ARCHITECTURE.ru.md`.                                                                                             |
| `DurationParts`        | ❌ нет (простая структура, 2 публичных поля)  | **Осознанное исключение** — см. ниже.                                                                                                                                                                            |
| `CivilDateTime`        | ❌ нет (простая структура, 7 публичных полей) | **Осознанное исключение** — см. ниже.                                                                                                                                                                            |
| `Time<S>`              | n/a (одно приватное поле + `PhantomData`)     | Корректно — публичных полей нет вовсе; весь доступ — через методы.                                                                                                                                               |
| `Duration`             | n/a (одно приватное поле)                     | Корректно — та же логика.                                                                                                                                                                                        |
| `LeapEntry`            | ❌ нет (простая структура, 2 публичных поля)  | **Помечен — см. рекомендацию ниже.**                                                                                                                                                                             |
| `LeapSeconds`          | n/a (непрозрачный, приватные поля)            | Корректно.                                                                                                                                                                                                       |
| `RuntimeLeapSeconds`   | n/a (непрозрачный, приватные поля)            | Корректно.                                                                                                                                                                                                       |

**`DurationParts` и `CivilDateTime` намеренно *не* `#[non_exhaustive]`.**
Оба — обычные структуры с полями, весь смысл которых — в создании
через литерал структуры (`DurationParts { seconds, nanos }`,
`CivilDateTime { year, month, … }`): пометка `#[non_exhaustive]` вынудила бы
всякого вызывающего пользоваться `::new()` или `Default` с последующей
мутацией, убив эргономику типа. Добавление поля в любой из них в будущем станет **minor**-
бампом по таблице выше, как и любое ломающее изменение литерала структуры; это
осознанная плата за возможность создавать структуру литералом.

**`LeapEntry` помечен для исправления в `0.x`-minor**: это простая структура
из двух полей (`tai_nanos: u64, tai_minus_utc: i32`), конструируемый напрямую
вызывающими при сборке собственной таблицы високосных секунд для
`RuntimeLeapSeconds`/`LeapSeconds::try_from_slice`. В отличие от
`DurationParts`/`CivilDateTime`, здесь нет веской эргономической причины
предпочесть литерал — `LeapEntry::new(tai_nanos, tai_minus_utc)` читается
ровно так же, как литерал, а все вызовы в текущем наборе тестов и фаззинг-тестов уже
используют двухаргументный паттерн конструктора. **Рекомендация:** пометить
`#[non_exhaustive]` в следующем minor-релизе, поскольку будущее поле
(например, человекочитаемая дата объявления или тег источника/происхождения,
различающий записи таблицы IERS и переданные приёмником) правдоподобно и
сейчас заблокировано раскрытым литералом.

## Аудит реэкспорта `pub use`

Сейчас в `lib.rs`:

```rust
pub use civil::CivilDateTime;
pub use convert::*;
pub use duration::*;
pub use epoch::*;
pub use error::*;
pub use leap::*;
pub use matrix::*;
pub use scale::*;
pub use time::*;
```

Каждый glob был сверен с тем, что он фактически реэкспортирует в корень
крейта (т.е. что становится доступным как `gnss_time::Foo`, а не только
`gnss_time::module::Foo`):

| `pub use`              | Что выводится в корень крейта                                                                                                              | Вердикт                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------  | --------------------------------------------------------------------------------------------------------------------------------           | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------                                                |
| `civil::CivilDateTime` | один именованный тип                                                                                                                       | ✅ Корректно — намеренный реэкспорт одного элемента, как у `Time`/`Duration`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `convert::*`           | `ConvertResult`, `IntoScale`, `IntoScaleWith`                                                                                              | ✅ Корректно — весь смысл слоя 4 в том, чтобы быть основным API для вызова.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `duration::*`          | `Duration`, `DurationParts`                                                                                                                | ✅ Корректно.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `epoch::*`             | `CivilDate`, все константы эпох (`TAI_EPOCH`, …, `UTC_EPOCH_UNIX_OFFSET_S`, …, `LEAP_SECONDS_AT_*`, `DAYS_GPS_TO_*`, `NANOS_GPS_TO_*`)     | ⚠️ **Чрезмерно широк.** Этот glob выводит в корень порядка 20 элементов, большинство из которых (`LEAP_SECONDS_AT_GLONASS_EPOCH`, `DAYS_GPS_TO_BEIDOU`, `NANOS_GPS_TO_GALILEO_EPOCH`, …) — константы вывода, используемые внутри `epoch.rs` в собственных `const`-проверках и ничем больше в крейте. Они не задействованы из `prelude.rs`, а их значения — часть контракта: каждое закреплено `const`-проверками в самом `epoch.rs` и разобранными примерами `docs/INVARIANTS.ru.md`, — так что реэкспорт добавляет публичную поверхность без добавления гибкости. См. рекомендацию ниже. |
| `error::*`             | `GnssTimeError`                                                                                                                            | ✅ Корректно.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `leap::*`              | `LeapSecondsProvider`, `LeapSeconds`, `RuntimeLeapSeconds`, `LeapEntry`, `LeapExtendError`, `RUNTIME_CAPACITY`, `gps_to_utc`, `utc_to_gps` | ✅ Корректно — все восемь задействованы из `prelude.rs`, что подтверждает: они задуманы как публичные.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `matrix::*`            | `ConversionMatrix`, `ScaleId`, `ConversionKind`                                                                                            | ✅ Корректно — и `ScaleId`, и `ConversionKind` — `#[non_exhaustive]`, что держит будущие добавления шкал patch-безопасными.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `scale::*`             | `TimeScale`, `Gps`, `Glonass`, `Galileo`, `Beidou`, `Tai`, `Utc`, `OffsetToTai`, `DisplayStyle`                                            | ⚠️ **`DisplayStyle` помечен.** *Тип* обязан остаться публичным — он является типом публичной ассоциированной константы `TimeScale::DISPLAY_STYLE` — но существует исключительно для того, чтобы `Display for Time<S>` выбирал формат, и ни одна публичная функция его не принимает и не возвращает, так что вызывающему нет причин *называть* его напрямую; `#[doc(hidden)]` (см. ниже) прячет его, не ломая контракт ассоциированной константы.                                                                                                                                          |
| `time::*`              | `Time`                                                                                                                                     | ✅ Корректно.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

**Итоговый вердикт:** найдены два излишних реэкспорта — внутренние константы
вывода `epoch` и `scale::DisplayStyle`. Ни один не является *багом* (ничего
не сломано), но оба расширяют публичную поверхность API элементами, на
которые не предполагалось полагаться, — именно это и решает
`#[doc(hidden)]`, не меняя поведения.

## Внутренние элементы, которые следует пометить `#[doc(hidden)]`

`#[doc(hidden)]` оставляет элемент технически публичным (если
существующий код на него ссылается, он не сломается), но убирает его из
генерируемой документации и подаёт сигнал «не используйте это». Это правильный инструмент здесь, потому что ни один
из элементов ниже нельзя сделать *действительно* приватным, не сломав
механизм реэкспорта через glob, через который они доступны (`pub use epoch::*`,
`pub use scale::*`), — цель в том, чтобы убрать их из публичной документации, а не
менять то, что компилируется.

| Элемент                                                                                                                          | Расположение | Обоснование                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------                                                                                       |
| `LEAP_SECONDS_AT_GPS_EPOCH`, `LEAP_SECONDS_AT_GLONASS_EPOCH`, `LEAP_SECONDS_AT_GALILEO_EPOCH`, `LEAP_SECONDS_AT_BEIDOU_EPOCH`    | `epoch.rs`   | Используются только в собственных `const`-проверках `epoch.rs` и в разобранных примерах `docs/INVARIANTS.ru.md`. Из `prelude.rs` не задействованы.                                                                                                                                                                                                                                                                                                                      |
| `DAYS_GPS_TO_GALILEO`, `DAYS_GPS_TO_BEIDOU`, `DAYS_GPS_TO_GLONASS`, `DAYS_UNIX_TO_GPS`                                           | `epoch.rs`   | То же — только внутренний вывод.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `NANOS_GPS_TO_GALILEO_EPOCH`, `NANOS_GPS_TO_BEIDOU_EPOCH_CALENDAR`                                                               | `epoch.rs`   | То же.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `DisplayStyle` (сам тип и его варианты)                                                                                          | `scale.rs`   | Тип нельзя сделать приватным — он является типом публичной ассоциированной константы `TimeScale::DISPLAY_STYLE`, — но существует только для внутреннего `match` в `Display for Time<S>`, и ни одна публичная функция не принимает и не возвращает `DisplayStyle`; `#[doc(hidden)]` держит `S::DISPLAY_STYLE` рабочим, сигнализируя «не называйте тип напрямую».                                                                                                         |
| `pub mod serde_impls`                                                                                                            | `lib.rs`     | Модуль содержит только `impl`-блоки трейтов (обнаруживаются компилятором автоматически, по пути никогда не вызываются) плюс их приватные вспомогательные типы (`TimeVisitor`, `DurationVisitor`, перечисления ключей полей и т.д. — см. `docs/ARCHITECTURE.ru.md#поддержка-serde-feature--serde`). Ничему внутри не нужен публичный путь; `#[doc(hidden)] pub mod serde_impls;` держит `impl` активными, убирая пустую, сбивающую с толку запись из вывода `cargo doc`. |
| модуль `tables`                                                                                                                  | `lib.rs`     | Уже `mod tables;` (приватный, не `pub mod`) — корректно как есть; перечислен здесь лишь для подтверждения, что аудит его проверил.                                                                                                                                                                                                                                                                                                                                      |

**Что прятать *не* следует**, для контраста: `LeapEntry`, несмотря на
пометку под `#[non_exhaustive]` выше, — подлинно публичное API (для сборки
собственной таблицы високосных секунд он обязателен) и должен оставаться
полностью документированным.

## Покрытие док-тестов

Каждый rust-блок кода в doc-комментариях публичного элемента был проверен на
то, компилируется ли он как обычный док-тест (т.е. не помечен ли `ignore`,
`no_run` там, где `run` на самом деле сработал бы, или `compile_fail` там, где
замысел — исполняемый код).

**Результат аудита:** каждый rust-блок кода в текущих doc-комментариях крейта —
обычный, без аннотаций, фрейм, — то есть `cargo test --doc` уже компилирует и
запускает их все, и ни одного `ignore` нигде в крейте нет. Сюда входят
примеры уровня модуля в `lib.rs`, `prelude.rs`, `civil.rs` и все примеры для
отдельных методов в `time.rs`, `duration.rs`, `leap.rs`, `convert.rs` и
`epoch.rs`.

Единственное оправданное использование нестандартной аннотации —
`examples/no_domain_mixing.rs`: это *отдельный файл-пример*, демонстрирующий
**ошибку компиляции** (смешение арифметики `Time<Gps>` и `Time<Glonass>`) —
это не док-тест, и `cargo test --doc` его вовсе не собирает; он существует
просто как наглядный пример для документации, на который
ссылается `docs/INVARIANTS.ru.md` ([I-1](INVARIANTS.ru.md#i-1-изоляция-доменов)),
и по этой причине корректно исключён из сборочного списка `[[example]]`
крейта (иначе он не прошёл бы `cargo build --examples` — в этом и смысл).

**Действий не требуется** сверх постоянного контроля — см. ниже.

## Контроль в CI

`cargo test --doc` ранее не был отдельным именованным шагом CI (он выполняется
неявно в составе `cargo test`, но его падение легко пропустить среди сотен имён
модульных и интеграционных тестов). Добавьте явный шаг, чтобы сломанный док-тест стал
однозначно виден в выводе CI:

```yaml
# .github/workflows/ci.yml — добавить рядом с существующим test-заданием
  doctest:
    name: doc-tests
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
      - name: cargo test --doc (default features)
        run: cargo test --doc
      - name: cargo test --doc (all features)
        run: cargo test --doc --all-features
```

Запуск один раз с фичами по умолчанию и второй раз с `--all-features` важен
именно из-за док-примеров `# #[cfg(feature = "serde")] { … }` в `lib.rs` и
фрагментов под serde-фичей в `civil.rs` — док-тест внутри блока
`#[cfg(feature = "...")]` молча пропускается (не падает), когда фича
выключена, поэтому прогон с `--all-features` — единственный, который реально
компилирует и исполняет эти примеры.

`justfile` получает парный рецепт для локального использования:

```just
# Запуск всех док-тестов (default + all-features)
doctest:
    cargo test --doc
    cargo test --doc --all-features
```

а существующий рецепт `ci` (`lint test-all check-embedded doc-check`) должен
его вызывать: `ci: lint test-all doctest check-embedded doc-check`.
